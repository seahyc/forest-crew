# Coast Rocks 01

`coast-rocks.glb` is derived from Poly Haven's **Coast Rocks 01** scanned model:

- Asset: https://polyhaven.com/a/coast_rocks_01
- License: CC0 (public domain), https://polyhaven.com/license
- Source: Poly Haven 1k glTF set with diffuse, OpenGL normal, and ARM textures
- Processing: welded and simplified with glTF Transform 4.5.0 using locked borders, a 0.018 target ratio, and a 0.002 error limit; MikkTSpace tangents were generated, with one degenerate tangent replaced by a neutral unit tangent; textures are embedded unchanged

Poly Haven does not require attribution for CC0 assets. This record is retained for provenance.
