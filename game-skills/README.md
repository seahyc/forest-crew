# Illustrative learned-skill outputs

These authored `SKILL.md` examples illustrate what agents might discover through gameplay. They are not a starter loadout, a prescribed skill tree, runtime seed data or globally installed coding-assistant skills. The live agents must develop their own methods from actual experiences; their names, content and graph may differ completely.

- [Establish water supply](establish-water-supply/SKILL.md): possible coordinated setup method.
- [Hand over a post](handover-post/SKILL.md): possible lesson after a coverage failure.
- [Recover lost pressure](recover-pressure/SKILL.md): possible diagnosis method.
- [Teach a recruit](teach-recruit/SKILL.md): possible method for sharing experience.

These describe stylised game rules, not real emergency procedures. See [emergent learning and the skill graph](../SKILLS.md) and [backstage evaluation scenarios](TRIALS.md). No live learning or transfer has been measured yet.
